# Hidex-site

This repository holds two independent things under the HIDEX org:

- **`index.html`** — the static marketing site for HIDEX (the software
  division landing page: houseX, NearbyYou, contact info). No build step;
  just a single HTML file.
- **`flutter_app/`** and **`supabase/`** — a Bible app (Flutter +
  Supabase + Firebase) built from scratch in this repo. See
  **[`flutter_app/README.md`](flutter_app/README.md)** for the full
  setup guide, architecture, and what's built vs. not yet built.
